# 👁️ Computer Vision

Módulo de **Visión por Computadora** del programa MAIA. Cubre los fundamentos modernos de visión computacional usando PyTorch, desde CNNs clásicas hasta transformers visuales y representaciones 3D neurales.

---

## 🎯 Objetivos de aprendizaje

- Dominar las primitivas de PyTorch para visión (tensores, dataloaders, transforms)
- Implementar y entrenar CNNs para clasificación y segmentación
- Comprender y aplicar Vision Transformers (ViT) y CLIP
- Explorar representaciones 3D implícitas con NeRF
- Trabajar con datasets de visión: ImageNet, CIFAR, COCO

# 🌐 MLNS — Machine Learning para Network Science

Módulo de **Machine Learning aplicado a Network Science** del programa MAIA. Combina técnicas de ML con análisis de grafos y redes complejas, con enfoque en aplicaciones de clasificación de texto y análisis de datos estructurados.

---

## 📚 Contenido

| Carpeta | Descripción |
|---------|-------------|
| [Microproyecto1/](./Microproyecto1/) | Clasificación multi-label de textos de ODS (Objetivos de Desarrollo Sostenible) |
| [Microproyecto2/](./Microproyecto2/) | Continuación: modelos avanzados de clasificación de texto |

---

## 🎯 Objetivos de aprendizaje

- Aplicar técnicas de NLP clásico y moderno a grandes corpus de texto
- Implementar clasificadores multi-label con scikit-learn y PyTorch
- Analizar datasets estructurados con pandas y matplotlib
- Integrar representaciones de grafos con ML (GNNs, node embeddings)
- Evaluar con métricas de multi-label: hamming loss, micro/macro F1

---

## 🚀 Configuración del entorno

```bash
pip install scikit-learn pandas numpy matplotlib
pip install torch transformers datasets
pip install networkx  # para análisis de grafos
```

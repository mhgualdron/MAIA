# Microproyecto 1 — Clasificación con Deep Learning

## Descripción

Primer microproyecto evaluado del módulo de Deep Learning. Implementación y entrenamiento de una arquitectura CNN para clasificación de imágenes/datos.

## Archivos

| Archivo | Descripción |
|---------|-------------|
| [`main.ipynb`](./main.ipynb) | Notebook principal con desarrollo completo del proyecto |

## Contenido del proyecto

- Carga y preprocesamiento del dataset
- Diseño e implementación de la arquitectura CNN
- Entrenamiento con validación y curvas de aprendizaje
- Evaluación de métricas (accuracy, F1, matriz de confusión)
- Análisis de resultados y conclusiones

## Cómo ejecutar

```bash
# En Google Colab (recomendado)
# Abrir main.ipynb y ejecutar todas las celdas

# En local
jupyter notebook main.ipynb
```

# Microproyecto 2 — Modelos Secuenciales

## Descripción

Segundo microproyecto evaluado. Implementación de modelos secuenciales (RNN/LSTM/GRU) para análisis o predicción de series temporales o texto.

## Archivos

| Archivo | Descripción |
|---------|-------------|
| [`main.ipynb`](./main.ipynb) | Notebook principal con el desarrollo completo |

## Contenido del proyecto

- Preprocesamiento de datos secuenciales
- Implementación de arquitectura RNN / LSTM
- Entrenamiento y ajuste de hiperparámetros
- Evaluación y análisis de resultados

## Cómo ejecutar

```bash
jupyter notebook main.ipynb
```

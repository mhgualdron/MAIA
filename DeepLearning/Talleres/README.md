# 🛠️ Talleres — Deep Learning

Talleres de frameworks y técnicas de Deep Learning.

## Contenido

| Notebook | Descripción |
|----------|-------------|
| [`TutorialPytorch.ipynb`](./TutorialPytorch.ipynb) | Tutorial completo de PyTorch: tensores, autograd, módulos, entrenamiento |
| [`Tutorial_Tensorflow.ipynb`](./Tutorial_Tensorflow.ipynb) | Tutorial de TensorFlow/Keras: Sequential API, capas, callbacks |
| [`TallerRedesNeuronales1.ipynb`](./TallerRedesNeuronales1.ipynb) | Redes neuronales densas: backpropagation, activaciones, regularización |
| [`TallerRedesNeuronales2.ipynb`](./TallerRedesNeuronales2.ipynb) | Optimizadores, batch normalization, dropout, learning rate scheduling |
| [`TallerVAEP2.ipynb`](./TallerVAEP2.ipynb) | Variational Autoencoders: espacio latente, reparametrization trick |

## Objetivo

Estos talleres sirven como base práctica para dominar los frameworks antes de los laboratorios y microproyectos. Se recomienda hacerlos en este orden:

1. `TutorialPytorch.ipynb` o `Tutorial_Tensorflow.ipynb`
2. `TallerRedesNeuronales1.ipynb`
3. `TallerRedesNeuronales2.ipynb`
4. `TallerVAEP2.ipynb`

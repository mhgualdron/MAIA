# 💬 NLP — Procesamiento de Lenguaje Natural

Módulo de **Procesamiento de Lenguaje Natural** del programa MAIA. Explora los fundamentos y técnicas modernas de NLP, desde embeddings clásicos hasta modelos de lenguaje de gran escala basados en Transformers.

## 🎯 Objetivos de aprendizaje

- Comprender representaciones de texto: bag-of-words, TF-IDF, word embeddings
- Implementar modelos de lenguaje estadísticos y neuronales
- Explorar arquitecturas Transformer para NLP (BERT, GPT)
- Aplicar fine-tuning a modelos pre-entrenados de HuggingFace
- Resolver tareas NLP: clasificación, NER, generación de texto, QA

# 🧠 MAIA — Maestría en Inteligencia Artificial

Repositorio de trabajos, proyectos y experimentos del programa **MAIA** (Maestría en Inteligencia Artificial) de la **Universidad de los Andes**.

Cada carpeta corresponde a una materia o área de trabajo del programa. Aquí encontrarás laboratorios, microproyectos, proyectos finales y experimentos de investigación aplicada.

## 🗂️ Estructura del repositorio

```
MAIA/
├── DeepLearning/        # CNNs, RNNs, Transformers, ViT
│   ├── Laboratorios/    # Notebooks de práctica guiada
│   ├── Talleres/        # Talleres de frameworks (PyTorch, TF)
│   ├── Microproyecto1-4/# Proyectos evaluados
│   └── AudioAPP/        # App FastAPI de clasificación de audio
├── ComputerVision/      # Visión por computadora
├── NLP/                 # Procesamiento de lenguaje natural
├── MLNS/                # ML para Network Science
├── MLS/                 # ML en Salud
├── RL/                  # Reinforcement Learning
│   ├── notebooks/       # Tutoriales y laboratorios
│   └── Proyecto/        # Agente RL para laberintos
├── CloudNativeApps/     # Microservicios, K8s, Terraform, AWS
├── Developments/        # Experimentos LLM (RAG, Fine-Tuning)
├── Defensa/             # Proyecto final de maestría
└── MeLi/                # Challenge técnico MercadoLibre
```

- **Data**: PostgreSQL · pandas · NumPy
- **Notebooks**: Jupyter · Google Colab
